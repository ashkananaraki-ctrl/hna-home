# H&A.HOME — نسخه آماده توسعه و تحویل

این نسخه شامل فروشگاه، سبد خرید، ثبت سفارش، پنل مدیریت، مدیریت محصولات و سیستم نظر/امتیاز مشتریان است.

## اجرا

```bash
npm install
```

فایل `.env.example` را به `.env` تبدیل کنید و مقدارهای واقعی مدیر را قرار دهید، سپس:

```bash
npm start
```

سایت روی `http://localhost:3000` اجرا می‌شود.

## امکانات اصلی

- مدیریت محصولات بدون سیستم موجودی/انبار
- دسته‌بندی محصولات
- آپلود تصویر محصول
- سبد خرید و تغییر تعداد
- ثبت سفارش
- هزینه ارسال که روی سرور تعیین می‌شود و از سمت مشتری قابل دستکاری نیست
- پنل مدیریت سفارش‌ها
- تغییر وضعیت سفارش
- مدیریت نظرات و امتیازها
- ثبت نظر فقط برای خرید تأییدشده
- نمایش امتیاز میانگین و تعداد نظر
- Structured Data محصول و Aggregate Rating برای کمک به نمایش Rich Result در Google
- محدودیت ورود پنل مدیریت
- عدم قرار گرفتن `.env` در نسخه قابل تحویل
- طراحی واکنش‌گرا برای موبایل

## نکته مهم درباره Google

پیاده‌سازی فنی Review و AggregateRating انجام شده، اما نمایش ستاره در نتایج Google تضمینی نیست و تصمیم نهایی با Google است.

## AI

برای AI باید مشخص شود دقیقاً چه قابلیتی می‌خواهید (چت‌بات، پیشنهاد محصول، تولید توضیحات، پاسخ‌گویی و...) و از چه سرویس/مدلی استفاده شود. این نسخه عمداً کلید API یا سرویس AI را داخل پروژه قرار نمی‌دهد.


## آدرس رایگان و انتشار سایت

این پروژه برای انتشار رایگان روی Render آماده شده است. Render برای Web Service رایگان یک آدرس `onrender.com` می‌دهد؛ بعد از Deploy آدرس سرویس شما به شکل `https://نام-سرویس.onrender.com` خواهد بود. برای پروژه‌های تستی/نمونه مناسب است، اما سرویس رایگان پس از ۱۵ دقیقه بدون درخواست به حالت sleep می‌رود و فایل‌های محلی مثل `products.json` و تصاویر روی ری‌استارت/Deploy پایدار نیستند. بنابراین برای فروشگاه واقعی باید بعداً ذخیره‌سازی را به دیتابیس و فضای فایل دائمی منتقل کرد.

### مراحل انتشار
1. کل پوشه پروژه را در یک مخزن GitHub قرار بده (فایل `.env` را آپلود نکن).
2. در Render یک Web Service بساز و مخزن GitHub را وصل کن.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. Plan: `Free`
6. متغیرهای محیطی `ADMIN_USERNAME` و `ADMIN_PASSWORD` را در Render وارد کن. `SESSION_SECRET` با فایل `render.yaml` به‌صورت خودکار ساخته می‌شود.
7. بعد از Deploy، Render آدرس رایگان `onrender.com` را می‌دهد.

`render.yaml` و مسیر `/health` برای همین انتشار آماده شده‌اند.
